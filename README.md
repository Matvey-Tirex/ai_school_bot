Для работы бота заполните данные в файле env.py

**Ознакомится перед стартом**
- Прежде чем начать работу вам надо всатавить свои токены в env.py

**Функции бота**:
- Проверка на ошибки рукописного текста с фотографии, которую вы отправляете боту
- Выбирай типы проверки теста для разных ситуаций

**Доп информация**
- Вы можете поставить себе неограниченное количество запросов в фаиле с вашим айди. Нужно выбрать строку "status" : "user" и вместо user ввести admin
